## Bugs and ideas

Open an issue on GitHub: [github.com/siddharthborderwala/tray/issues](https://github.com/siddharthborderwala/tray/issues). Say what you ran, what you expected and what happened instead. The output of `tray --version`, and of the failing command with `--json`, helps a lot.

Pull requests are welcome too. For anything large, open an issue first so we can agree on the shape.

## Security

Please don't open a public issue for a vulnerability. Report it privately through GitHub's private vulnerability reporting: [report a vulnerability](https://github.com/siddharthborderwala/tray/security/advisories/new). You'll get a reply within a few days.
